### 问题2: 组合投资界面数据迭代错误 ✅

**错误信息**:
```
ERROR 更新组合数据失败: 'int' object is not iterable
```

**问题位置**: `ui/components/portfolio_investment/main_view.py` 第870行

**问题原因**:
- `get_positions()`方法返回类型不一致（可能是dict也可能是其他类型）
- 代码直接尝试迭代`positions`，没有类型检查
- 当positions为非列表类型时导致迭代失败

**原始代码**:
```python
for i, pos in enumerate(positions[:10]):  # positions可能不是列表
    position_table.insertRow(i)
    ...
```

**修复方案**:
```python
# 处理positions可能是字典或列表的情况
if isinstance(positions, dict):
    # 如果是字典，将值转换为列表
    positions_list = list(positions.values())
elif isinstance(positions, list):
    # 如果是列表，直接使用
    positions_list = positions
else:
    # 其他类型，记录错误并返回
    self.logger.error("positions类型错误: %s, 值: %s", type(positions), positions)
    return

# 限制显示数量，避免表格过大
for i, pos in enumerate(positions_list[:10]):
    # 确保pos是字典类型
    if not isinstance(pos, dict):
        self.logger.warning("持仓项不是字典类型: %s", type(pos))
        continue
    ...
```

**修复文件**: `ui/components/portfolio_investment/main_view.py`

**修复内容**:
1. 添加类型检查逻辑
2. 支持dict和list两种数据类型
3. 添加类型错误日志记录
4. 对每个持仓项也进行类型验证

**验证结果**: ✅ **修复成功**
- "ERROR 更新组合数据失败"错误消失
- 组合投资界面正常运行
- 测试日志干净整洁

## 🎯 技术要点

### 1. 导入路径最佳实践

❌ **不推荐**:
```python
from config import ConfigManager  # 模糊不清
```

✅ **推荐**:
```python
from backend.config import ConfigManager  # 明确路径
```

✅ **更推荐（带容错）**:
```python
try:
    from backend.config import ConfigManager
except ImportError:
    # Fallback实现
    class ConfigManager:
        ...
```

### 2. 类型安全处理

❌ **不推荐**:
```python
for item in data:  # 假设data是列表
    process(item)
```

✅ **推荐**:
```python
# 类型检查
if isinstance(data, dict):
    data_list = list(data.values())
elif isinstance(data, list):
    data_list = data
else:
    logger.error("数据类型错误: %s", type(data))
    return

for item in data_list:
    if isinstance(item, dict):  # 再次验证
        process(item)
```
