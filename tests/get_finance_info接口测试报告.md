## 总结与建议

### ✅ **好消息：所有品种类型都支持！**

经过使用实际存在的品种代码测试，`get_finance_info` 接口对以下所有品种类型都**100%支持**：

1. **北交所股票**（市场代码2，92开头）✅
2. **深圳可转债**（123xxx, 127xxx, 128xxx）✅
3. **上海可转债**（110xxx）✅
4. **深圳ETF**（159xxx）✅
5. **上海ETF**（510xxx, 511xxx）✅
6. **深圳LOF**（161xxx, 163xxx, 160xxx）✅
7. **上海LOF**（501xxx）✅

### 🔑 关键发现

1. **北交所股票代码变更**：
   - ✅ 新代码格式：92开头（如 920000）
   - ❌ 旧代码格式：4xxxxx、8xxxxx（已废弃）

2. **已退市品种会返回空数据**：
   - 必须使用实际存在的品种代码
   - 建议从品种列表缓存中获取实际代码

### 🎯 推荐实施方案

直接使用 `get_finance_info` 接口查询所有品种的上市日期！

```python
from backend.infrastructure.tdx_asyncio import AsyncTdxHq_API
from datetime import datetime

async def get_ipo_date(client: AsyncTdxHq_API, market: int, code: str):
    """获取品种上市日期

    Args:
        client: tdx客户端
        market: 市场代码（0=深圳，1=上海，2=北交所）
        code: 品种代码

    Returns:
        上市日期（date对象）或None
    """
    finance_info = await client.get_finance_info(market=market, code=code)

    if finance_info:
        ipo_timestamp = finance_info.get("ipo_date")
        if ipo_timestamp and ipo_timestamp > 0:
            ipo_str = str(int(ipo_timestamp)).zfill(8)
            if len(ipo_str) == 8:
                return datetime.strptime(ipo_str, "%Y%m%d").date()

    return None
```

**适用范围：**
- ✅ 北交所股票（92开头）
- ✅ 沪深可转债（110xxx, 123xxx, 127xxx, 128xxx）
- ✅ 沪深ETF（159xxx, 510xxx, 511xxx）
- ✅ 沪深LOF（161xxx, 163xxx, 501xxx）

**注意事项：**
- 确保使用实际存在的品种代码（建议从品种列表缓存获取）
- 已退市品种会返回空数据

## 技术说明

### get_finance_info 接口返回的33个字段

```python
{
    "market": int,              # 市场代码
    "code": str,                # 品种代码
    "ipo_date": int,            # 上市日期（YYYYMMDD格式，如20210421）
    "liutongguben": float,      # 流通股本（股）
    "zongguben": float,         # 总股本（股）
    "zongzichan": float,        # 总资产（元）
    "jingzichan": float,        # 净资产（元）
    "zhuyingshouru": float,     # 主营收入（元）
    "jinglirun": float,         # 净利润（元）
    "meigujingzichan": float,   # 每股净资产（元）
    "industry": int,            # 行业代码
    "province": int,            # 省份代码
    "updated_date": int,        # 更新日期
    # ... 还有20个财务指标字段
}
```

### ipo_date 字段的解析方法
