## 🔍 问题与解决方案

### 问题1: 服务未注册
**现象**: 首次运行时提示"SERVICE_NOT_FOUND"
**原因**: 测试夹具未调用`initialize_services()`
**解决**: 在夹具中添加服务初始化逻辑
**状态**: ✅ 已解决

### 问题2: 数据结构验证失败
**现象**: 缺少`market`字段
**原因**: 缓存文件保存的是mootdx原始数据，`market`字段是动态生成的
**解决**: 调整验证逻辑，分别验证原始缓存和分类结果
**状态**: ✅ 已解决

### 问题3: QApp属性不存在
**现象**: `AttributeError: 'DataCenter' object has no attribute 'qApp'`
**原因**: 直接访问不存在的属性
**解决**: 使用`QApplication.instance()`获取应用实例
**状态**: ✅ 已解决

### 问题4: 网络超时
**现象**: mootdx连接超时
**原因**: 网络环境或服务器响应慢
**解决**: 增加超时时间或在网络稳定时重测
**状态**: ⏸️ 环境相关，非代码问题
