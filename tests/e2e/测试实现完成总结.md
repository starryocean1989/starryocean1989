## 🔬 技术细节

### API调用流程

```
china_stock_engine.reload_stock_list()
    ↓
stock_fetcher.fetch_all_stocks()
    ↓
mootdx.quotes.Quotes.stock_all()  [真实API]
    ↓
返回47,075个品种（22+26个服务器）
    ↓
stock_fetcher.cache_stock_list()
    ↓
保存到 data/cache/stock_list.parquet
```

### 品种分类流程

```
stock_fetcher.get_all_market_stocks()
    ↓
加载缓存文件（47,075个品种）
    ↓
按代码前缀过滤:
  - 上证（60/68开头）→ 2,287
  - 深证（00/30开头）→ 3,033
  - 北证（4/8开头）→ 基础筛选
    ↓
spblock.dat解析:
  - 北证A股（融资融券板块）→ 277
  - T+0基金 → 318
  - 含可转债 → 424
    ↓
合并结果: 6,339个品种 ✅
```

### 数据结构

**缓存文件字段**:
```python
[
    'code',           # 品种代码
    'volunit',        # 交易单位
    'decimal_point',  # 小数位数
    'name',           # 品种名称
    'pre_close',      # 前收盘价
    'cache_time'      # 缓存时间戳
]
```
