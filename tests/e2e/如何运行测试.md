# 如何运行数据中心E2E测试

## 快速开始

### 1. 安装依赖

```bash
pip install pytest pytest-qt pytest-timeout pandas
```

### 2. 运行所有E2E测试

```bash
# 从项目根目录运行
pytest tests/e2e/ -v
```

### 3. 运行特定测试

```bash
# 运行测试点1：缓存文件生成
pytest tests/e2e/test_data_center_reload_symbols.py::TestDataCenterReloadSymbols::test_symbol_cache_generation -v

# 运行测试点2：前端列表更新
pytest tests/e2e/test_data_center_reload_symbols.py::TestDataCenterReloadSymbols::test_frontend_list_update -v

# 运行完整E2E流程
pytest tests/e2e/test_data_center_reload_symbols.py::TestDataCenterReloadSymbols::test_complete_reload_flow -v
```

### 4. 运行快速冒烟测试

```bash
# 只运行快速测试（不调用真实API）
pytest tests/e2e/test_data_center_reload_symbols.py::test_service_availability -v
pytest tests/e2e/test_data_center_reload_symbols.py::test_widget_creation -v
```

## 测试说明

### 测试目标

验证数据中心"重新加载品种"按钮的两个核心功能：

1. **测试点1**：生成包含6000-7000个品种的本地缓存（`data/cache/stock_list.parquet`）
2. **测试点2**：缓存更新后自动同步到前端品种列表组件

### 技术栈

- **真实API**：使用mootdx真实API调用（需要网络连接）
- **品种来源**：API筛选品种（5200+）+ spblock.dat解析品种
- **超时限制**：180秒（充足的API调用时间）

### 预期结果

#### 测试点1成功标准：
- ✅ 缓存文件存在且大小 > 100KB
- ✅ 品种总数：6000-7000个
- ✅ 数据结构完整（包含code, name, market字段）
- ✅ 无重复品种代码
- ✅ 包含API筛选的品种（5000+）

#### 测试点2成功标准：
- ✅ 前端数据已更新且数量与缓存一致
- ✅ UI组件正确渲染（表格、标签等）
- ✅ 筛选和搜索功能正常工作

## 常见问题

### Q: 测试超时怎么办？

**A**: 如果网络慢，可以增加超时时间：

```python
@pytest.mark.timeout(300)  # 增加到300秒
```

### Q: 品种数量不在6000-7000范围内？

**A**: 可能原因：
- mootdx API返回数据异常
- spblock.dat文件不可用或已过期
- 过滤规则发生变化

检查日志查看详细的市场分布统计。

### Q: 如何查看详细日志？

**A**: 使用 `-s` 和 `--log-cli-level=DEBUG` 参数：

```bash
pytest tests/e2e/test_data_center_reload_symbols.py -v -s --log-cli-level=DEBUG
```

### Q: 测试会影响现有缓存吗？

**A**: 不会。测试会：
1. 自动备份现有缓存文件
2. 测试结束后恢复备份
3. 确保开发环境不受影响

## 进阶用法

### 使用标记筛选测试

```bash
# 只运行数据中心相关测试
pytest -m "data_center" -v

# 只运行E2E测试
pytest -m "e2e" -v

# 组合标记
pytest -m "e2e and data_center" -v
```

### 生成测试报告

```bash
# HTML报告
pytest tests/e2e/ --html=report.html --self-contained-html

# JUnit XML报告（CI/CD）
pytest tests/e2e/ --junitxml=junit.xml
```

### 并行测试（慎用）

```bash
# 安装pytest-xdist
pip install pytest-xdist

# 并行运行（注意：真实API可能有限流）
pytest tests/e2e/ -n auto
```

## 故障排查

### 1. import错误

确保在项目根目录运行测试：

```bash
cd C:\Users\USER\Desktop\terminal_v0.50
pytest tests/e2e/ -v
```

### 2. Qt相关错误

确保安装了PySide6：

```bash
pip install PySide6
```

### 3. 数据库锁定错误

关闭其他正在运行的应用实例。
