## ⚠️ 发现的问题

### 1. 组合投资界面运行时错误

**问题**: 在定时器更新时出现错误
```
ERROR 更新组合数据失败: 'int' object is not iterable
```

**影响**:
- 不影响测试框架本身
- 不影响其他界面测试
- 可能影响组合投资相关测试用例

**原因**: 组合投资界面的数据更新逻辑中存在类型错误

**建议**: 修复组合投资界面的数据更新方法

### 2. 测试执行速度

**观察**: 每个测试用例执行时间较长（10-15秒）

**原因**:
- 每次测试都完整初始化主窗口
- VnPy引擎初始化耗时
- 等待UI更新时间

**建议**:
- 优化fixture scope（session级别复用）
- 减少不必要的等待时间
- 使用更轻量的mock

## 🔧 已修复的问题

### 问题1: ConfigManager导入错误

**问题描述**: `ui/main_window.py`导入ConfigManager失败

**解决方案**: 修改导入路径
```python
from backend.config import ConfigManager
```

**状态**: ✅ 已修复

### 问题2: Fixtures未加载

**问题描述**: pytest找不到main_window等fixtures

**解决方案**: 在conftest.py中添加
```python
pytest_plugins = [
    "tests.test_ui_integration.fixtures.app_fixture",
    "tests.test_ui_integration.fixtures.ui_fixture",
    "tests.test_ui_integration.fixtures.mock_backend",
]
```

**状态**: ✅ 已修复
