```python
# ❌ 手动轮询
_waited = 0.0
while _waited < 3.0:
    _state = service_accessor.get_datasource_connection_state(datasource_service)

**修复后**：

from tests.test_e2e.utils.wait_helpers import wait_for_connection_state

await wait_for_connection_state(
    datasource_service,
    service_accessor,
    expected_pushing=True,
    timeout=3.0,
)
```

- ✅ 测试更稳定，条件满足即返回

### 三、Fixture配置优化（Medium Priority）

#### **3.1 autouse fixture 文档说明**

**问题**：`autouse=True` fixture 职责不明确，与全局fixture的关系不清晰。

**修复文件**：
1. `test_e2e_market_board_indicators.py`
2. `test_e2e_strategy_instance_lifecycle.py`

**添加的文档说明**：
```python
@pytest.fixture(autouse=True)
def setup_helper(self):
    """
    设置测试助手（每个测试方法自动运行）.

    注意：
    - autouse=True 意味着此fixture会在每个测试方法前自动执行
    - 为测试类实例注入 chart_helper，提供图表验证工具
    - 与conftest.py中的全局fixture独立，不会产生冲突
    - 测试方法可以通过 self.chart_helper 访问助手
    """
```

**效果**：
- ✅ Fixture职责明确
- ✅ 开发者理解成本降低
- ✅ 避免误用和冲突
