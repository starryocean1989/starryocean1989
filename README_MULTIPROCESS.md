## 技术架构

### 数据下载策略

**主板股票 + ETF**：
- API：`mootdx.Quotes.bars()`
- 优势：智能市场判断，支持各种ETF
- 覆盖：600xxx, 000xxx, 510xxx, 520xxx, 551xxx等

**北交所股票**：
- API：`TdxHq_API.get_security_bars(market=2)`
- 原因：mootdx.Quotes不支持market=2
- 覆盖：920xxx, 430xxx, 82/83/87/88开头

**降级方案**：
- mootdx.Quotes失败 → TdxHq_API
- 双层保障

### 品种过滤（4层）

```
1. volunit=100 → 排除债券（volunit=10）
2. name不含"债" → 排除债券指数
3. name不含"指数" → 排除一般指数
4. name不含"退市" → 排除退市股
5. 前缀筛选时排除000000-000999 → 排除指数区间
```

### 数据保存

```
1. 第一次检查：save_kline()开头检查原始DataFrame
2. 标准化处理：_standardize_dataframe()
3. 第二次检查：to_parquet()之前再次检查
→ 双重保障，防止生成损坏文件
```

## 注意事项

### 正常的空数据
以下情况返回空数据是正常的：
- 新上市股票（数据不足）
- 停牌股票（无交易）
- 已退市但未及时清理

### 系统要求
- 内存：推荐8GB+（48GB完美）
- CPU：推荐8核+（16核更佳）
- 网络：稳定的网络连接

### 推荐配置
- 10进程：适合8核CPU
- 15进程：适合12核+CPU
- 20+进程：谨慎使用，可能导致UI卡顿
