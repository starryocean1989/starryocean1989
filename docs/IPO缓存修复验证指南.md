## 常见问题

### Q1: IPO下载耗时超过5分钟怎么办？
**A**: 正常情况下应在2分钟内完成。如果超时：
1. 检查网络连接速度
2. 在"系统管理"模块重新测速服务器
3. 关闭其他占用网络的程序

### Q2: 管道通信异常是否正常？
**A**: 偶尔出现1-2次是正常的（网络波动或服务器响应慢）。系统会自动重试。
- 如果连续出现5次，系统会终止下载并继续启动
- 如果频繁出现，建议检查网络稳定性

### Q3: IPO下载失败后如何手动更新？
**A**: 两种方法：
1. **方法1**: 删除`data/terminal.db`，重新启动应用
2. **方法2**: 在"数据中心"模块，点击"更新IPO信息"按钮（待实现）

### Q4: 如何查看详细的错误日志？

1. 打开最新的AI日志文件：`logs/ai/startup_YYYYMMDD_HHMMSS.log`
2. 搜索关键字：`[IPO下载]`、`EOFError`、`BrokenPipeError`

## 技术细节

### 异常处理机制
```python
consecutive_errors = 0  # 连续错误计数器
max_consecutive_errors = 5  # 最大容忍5次

while completed < total_symbols:
    try:
        # 从结果队列获取数据
        symbol, result_data = self.result_queue.get(timeout=1)
        consecutive_errors = 0  # 成功后重置

    except (EOFError, BrokenPipeError, ConnectionError) as e:
        consecutive_errors += 1

        # 检查子进程状态
        alive_processes = [p for p in self.processes if p.is_alive()]

        if consecutive_errors >= max_consecutive_errors:
            # 终止下载，清理进程
            self._cleanup_processes()
            break

        if not alive_processes:
            # 所有进程都退出了
            break
```

# 下载前：显示预计耗时
