# 日志使用规范

## 概述

本文档定义了项目中统一的日志记录规范，确保日志的一致性、可读性和可追踪性。

## 日志级别定义

### DEBUG
- **使用场景**: 开发调试、详细流程跟踪
- **示例**: 函数参数、中间变量、数据转换步骤
- **是否存储**: 是
- **生产环境**: 可关闭

```python
self.logger.debug("处理数据: symbol=%s, bars=%d", symbol, len(bars))
```

### INFO  
- **使用场景**: 正常业务流程
- **示例**: 服务启动、操作完成、状态变更
- **是否存储**: 是
- **生产环境**: 开启

```python
self.logger.info("数据下载完成: symbol=%s, count=%d", symbol, count)
```

### WARNING
- **使用场景**: 可恢复异常、潜在问题
- **示例**: 网络重试、数据缺失、配置降级
- **是否存储**: 是
- **生产环境**: 开启

```python
self.logger.warning("网关连接失败，将在5秒后重试: gateway=%s", gateway_name)
```

### ERROR
- **使用场景**: 业务错误、操作失败
- **示例**: 操作失败、数据错误、服务不可用
- **是否存储**: 是
- **生产环境**: 开启
- **触发告警**: 是

```python
self.logger.error("订单发送失败: order_id=%s, error=%s", order_id, error, exc_info=True)
```

### CRITICAL
- **使用场景**: 系统错误、严重故障
- **示例**: 服务崩溃、数据损坏、安全威胁
- **是否存储**: 是
- **生产环境**: 开启
- **触发告警**: 是（最高优先级）

```python
self.logger.critical("数据库连接失败，服务无法继续: %s", error, exc_info=True)
```

## LoggerMixin 使用指南

### 基本使用

```python
from backend.core.logging_mixin import LoggerMixin

class MyService(LoggerMixin):
    def __init__(self):
        super().__init__()
        self.logger.info("服务已创建")
    
    def process_data(self, data):
        self.logger.debug("开始处理数据: size=%d", len(data))
        try:
            result = self._do_process(data)
            self.logger.info("数据处理完成: result_count=%d", len(result))
            return result
        except Exception as e:
            self.logger.error("数据处理失败: %s", e, exc_info=True)
            raise
```

### 性能日志

```python
import time

def query_database(self, sql):
    start_time = time.time()
    try:
        result = self.db.execute(sql)
        duration_ms = (time.time() - start_time) * 1000
        
        self.log_performance(
            operation="数据库查询",
            duration_ms=duration_ms,
            success=True,
            extra={"sql": sql, "row_count": len(result)}
        )
        return result
    except Exception as e:
        duration_ms = (time.time() - start_time) * 1000
        self.log_performance(
            operation="数据库查询",
            duration_ms=duration_ms,
            success=False,
            extra={"sql": sql, "error": str(e)}
        )
        raise
```

### 操作日志

```python
def execute_strategy(self, strategy_name, params):
    # 记录操作开始
    self.log_operation_start("策略执行", strategy=strategy_name, params=params)
    
    try:
        result = self.backtest_engine.run(strategy_name, params)
        
        # 记录操作成功
        self.log_operation_success(
            "策略执行",
            return_pct=result["return"],
            sharpe=result["sharpe"]
        )
        return result
        
    except Exception as e:
        # 记录操作失败
        self.log_operation_failure(
            "策略执行",
            error=e,
            strategy=strategy_name
        )
        raise
```

## 日志记录位置规范

### 服务层日志点

1. **服务初始化**
```python
def _do_initialize(self) -> bool:
    self.logger.info("初始化服务: %s", self.service_name)
    try:
        # 初始化逻辑
        self.logger.info("服务初始化成功: %s", self.service_name)
        return True
    except Exception as e:
        self.logger.error("服务初始化失败: %s", e, exc_info=True)
        return False
```

2. **服务方法调用**
```python
def process_request(self, request_id, params):
    self.logger.debug("处理请求: request_id=%s, params=%s", request_id, params)
    try:
        result = self._execute(params)
        self.logger.info("请求处理完成: request_id=%s", request_id)
        return result
    except Exception as e:
        self.logger.error("请求处理失败: request_id=%s, error=%s", request_id, e, exc_info=True)
        raise
```

3. **数据库操作**
```python
def save_to_database(self, data):
    self.logger.debug("保存数据到数据库: count=%d", len(data))
    try:
        self.db.insert(data)
        self.logger.info("数据保存成功: count=%d", len(data))
    except Exception as e:
        self.logger.error("数据库保存失败: %s", e, exc_info=True)
        raise
```

4. **外部API调用**
```python
def call_external_api(self, endpoint, params):
    self.logger.info("调用外部API: endpoint=%s", endpoint)
    try:
        response = self.http_client.get(endpoint, params=params)
        self.logger.info("API调用成功: endpoint=%s, status=%d", endpoint, response.status_code)
        return response
    except Exception as e:
        self.logger.error("API调用失败: endpoint=%s, error=%s", endpoint, e, exc_info=True)
        raise
```

### 业务层日志点

1. **业务流程关键节点**
```python
def download_market_data(self, symbols, date_range):
    self.logger.info("开始下载行情数据: symbols=%d, date_range=%s", len(symbols), date_range)
    
    for i, symbol in enumerate(symbols):
        self.logger.debug("下载进度: %d/%d, symbol=%s", i+1, len(symbols), symbol)
        try:
            self._download_symbol(symbol, date_range)
        except Exception as e:
            self.logger.warning("符号下载失败: symbol=%s, error=%s", symbol, e)
    
    self.logger.info("行情数据下载完成: success=%d, failed=%d", success_count, failed_count)
```

2. **数据校验**
```python
def validate_data(self, data):
    self.logger.debug("开始数据校验: count=%d", len(data))
    
    invalid_count = 0
    for record in data:
        if not self._is_valid(record):
            invalid_count += 1
            self.logger.warning("发现无效数据: record_id=%s", record.id)
    
    if invalid_count > 0:
        self.logger.warning("数据校验完成: invalid_count=%d", invalid_count)
    else:
        self.logger.info("数据校验完成: all valid")
```

## 格式化规范

### 消息格式

1. **使用 % 格式化（推荐）**
```python
self.logger.info("用户登录: user_id=%s, ip=%s", user_id, ip)
```

2. **不要使用 f-string**
```python
# ❌ 错误示例
self.logger.info(f"用户登录: user_id={user_id}, ip={ip}")

# ✅ 正确示例
self.logger.info("用户登录: user_id=%s, ip=%s", user_id, ip)
```

### 敏感信息脱敏

```python
def mask_sensitive_data(api_key: str) -> str:
    """脱敏API密钥."""
    if len(api_key) > 8:
        return f"{api_key[:4]}...{api_key[-4:]}"
    return "***"

# 使用
self.logger.info("API密钥已配置: %s", mask_sensitive_data(api_key))
```

## 异常处理

### 记录异常堆栈

```python
try:
    risky_operation()
except Exception as e:
    # 使用 exc_info=True 记录完整堆栈
    self.logger.error("操作失败: %s", e, exc_info=True)
    raise
```

### 异常上下文

```python
try:
    result = self.process_data(data)
except ValueError as e:
    self.logger.error("数据处理错误: data_type=%s, error=%s", type(data).__name__, e, exc_info=True)
    raise
except NetworkError as e:
    self.logger.error("网络错误: endpoint=%s, error=%s", endpoint, e, exc_info=True)
    raise
```

## 性能最佳实践

### 避免在循环中记录DEBUG日志

```python
# ❌ 错误示例
for item in large_list:
    self.logger.debug("处理项: %s", item)  # 性能问题

# ✅ 正确示例
self.logger.debug("开始处理列表: count=%d", len(large_list))
for i, item in enumerate(large_list):
    if i % 1000 == 0:  # 每1000条记录一次
        self.logger.debug("处理进度: %d/%d", i, len(large_list))
```

### 延迟字符串格式化

```python
# ❌ 错误示例
self.logger.debug(f"复杂计算结果: {expensive_calculation()}")

# ✅ 正确示例
if self.logger.isEnabledFor(logging.DEBUG):
    self.logger.debug("复杂计算结果: %s", expensive_calculation())
```

## 总结

遵循本规范可以确保：
1. 日志的一致性和可读性
2. 便于问题排查和追踪
3. 支持性能分析和优化
4. 触发合适的告警
5. 满足审计和合规要求
