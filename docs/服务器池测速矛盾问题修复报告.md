## 🔍 根本原因

### Bug定位

**文件**: `backend/infrastructure/data_module_vnpy/data_module.py`
**行号**: 2405
**错误代码**:
```python
cache_file = ConfigManager.get_cache_dir() / "server_pool_cache.json"  # ❌ 错误
```

**错误原因**:
- `get_cache_dir()` 是 `ConfigManager` 类的**实例方法**（需要 self 参数）
- 代码却使用**类名**直接调用，导致报错：`missing 1 required positional argument: 'self'`

#### 第一次调用（20:05:51）- 失败

- **结果**:
  - 第2405行代码错误，抛出异常
  - 被捕获后进入"无网络降级模式"
  - 跳过步骤2-7

#### 第二次调用（20:05:52）- 成功
- **调用者**: `ServerPoolManager.start()` 内部逻辑
- **位置**: `load_balancer.py` 第5362行

## ✅ 修复方案

### 代码修复

**修改**: `backend/infrastructure/data_module_vnpy/data_module.py` 第2405行
