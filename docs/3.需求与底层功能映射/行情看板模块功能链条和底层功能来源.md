## 📋 模块概述

行情看板模块是星辰量化终端的专业行情分析工具，采用单一界面设计，与一般股票行情软件的看盘界面无异。所有功能集成在一个综合的行情分析界面中，专注于行情展示和技术分析，不包含指标编写和回测功能。

### 🎯 核心定位

根据原始需求文档，行情看板界面采用**单一界面设计**，不拆分子界面：

- **界面特征**: 与一般股票行情软件的看盘界面无异
- **功能集成**: 所有功能集成在一个综合界面中
- **技术特点**: 多周期支持、实时兼容、数据录制
- **架构模式**: 单一界面架构（无子界面）

### 🔧 功能区域

行情看板界面包含以下4个核心功能区域：

1. **行情主图区**: K线图/分时线/Tick线/周期切换
2. **指标副图区**: 2-3个可隐藏的指标副图，支持指标切换
3. **叠加功能区**: 品种叠加功能和指标叠加功能
4. **控制功能区**: 坐标切换(普通/对数)/样式配置

### 🎯 技术特点

- **多周期支持**: 其他周期K线由日线、5min、1min这3类K线合成
- **实时兼容**: 支持交易时间和非交易时间使用
- **数据录制**: 实时数据推送时需要recording功能，配合历史数据收集当日数据
