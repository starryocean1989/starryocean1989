## 📋 模块概述

策略指标中心模块是星辰量化终端的策略/指标开发环境，提供策略文件管理、代码编写、AI助手、策略回测等核心功能。

### 🎯 核心定位

根据原始需求文档，策略中心界面采用**混合架构**，包含1个固有组件和2个子界面：

**固有组件**:
- **策略/指标管理器**: 内容区左侧竖条，文件管理器（树状图显示，支持拖动调整大小）

**子界面**:
1. **策略/指标编写子界面**: 代码编辑器（基于VSCode核心）+ AI助手
2. **策略/指标回测子界面**: 回测配置 + 回测结果展示

### 🔧 支持的策略类型

基于VnPy的6种策略模板：

- **algotrading**: 算法交易策略
- **ctastrategy**: CTA策略
- **optionmaster**: 期权策略
- **portfoliostrategy**: 组合策略（注意：单策略多品种，不是多策略）
- **scripttrader**: 脚本交易策略（完全空白模板）
- **spreadtrading**: 价差交易策略

### ⚠️ 重要数据服务说明

**策略回测界面所需数据由数据中心板块提供，后端包data_module_vnpy提供历史数据，实时数据集成式的数据服务。**
