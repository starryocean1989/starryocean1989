## 📋 模块概述

数据中心模块是星辰量化终端的数据管理解决方案，提供品种列表管理、本地数据查询、数据下载和数据源管理等核心数据服务。

### 🎯 核心定位

根据原始需求文档，数据中心界面包含4个子界面：

1. **品种列表子界面**: 品种展示/筛选搜索/缓存管理
2. **数据下载子界面**: 增量下载/进度监控（限制最近100天以内）
3. **本地数据子界面**: 数据查询/质量检查/自动修复
4. **数据源管理子界面**: 连接管理/配置验证/状态监控/录制功能

### 🔧 数据源支持

**数据源配置（5种，实际实现）**:

**实时推送网关（2种）**:
1. **轮询转为推送的数据转换器（PollingGateway）**: 无需账号密码，后端分析日期时间，交易时间开始定时向API轮询并推送数据，非交易时间不轮询也不推送
2. **虚拟实时数据推送网关（VirtualGateway）**: 无需账号密码，前端界面有日期时间选择框，启动推送前必须配置，点击启动后模拟从该时点推送数据

**历史数据源（3种）**:
3. **iFind数据源**: 机构级金融数据服务，提供专业级历史数据下载
4. **RQData数据源**: 量化投资数据平台，提供高质量历史数据
5. **Tushare数据源**: 金融数据接口，提供A股历史数据服务

**说明**: 历史数据源主要用于数据下载功能，不提供实时推送服务

- 品种数据获取完整

- `infrastructure/data_module_vnpy/engine.py` - data_module_vnpy核心引擎，提供品种列表获取方法
