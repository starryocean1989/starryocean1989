## 📋 模块概述

数据中心模块是星辰量化终端的数据管理解决方案，提供品种列表管理、本地数据查询、数据下载和数据源管理等核心数据服务。

### 🎯 核心定位

根据原始需求文档，数据中心界面包含4个子界面：

1. **品种列表子界面**: 品种展示/筛选搜索/缓存管理
2. **本地数据子界面**: 数据查询/质量检查/自动修复
3. **数据下载子界面**: 全量下载/自定义下载/进度监控
4. **数据源管理子界面**: 连接管理/配置验证/状态监控

### 🔧 数据源支持

- **iFind**: 需要账号密码配置，专业级金融数据服务
- **RQData**: 需要账号密码配置，高质量量化投资数据服务
- **Tushare**: 需要账号密码配置，全面的中国金融市场数据服务
- **data_engine**: 无需账号密码，一个能把轮询转为推送的数据转换器，当前连接了tdx_gateway的数据模块

## 功能链条映射（与原始需求对齐）

### 2.1 品种列表子界面

**功能描述**: 品种列表界面是一个可翻页的展示列表，后端连到data_module_vnpy包生成的品种列表缓存。品种列表、数据下载、本地数据是一个体系，都由data_module_vnpy包来完成。

#### 2.1.1 品种数据管理链条

**功能说明**:
- **重新加载品种按钮**: 点击时，data_module_vnpy包会调用data_module_vnpy的品种列表获取方法通过外部API请求所有品种的列表，然后保存为本地缓存，然后该缓存更新到前端的品种列表栏
- **刷新品种按钮**: 刷新品种的逻辑是不调用api请求数据，只把data_module_vnpy已经生成的不同品种的列表缓存更新到前端的品种列表栏
- **品种筛选功能**: 品种列表还应有按交易所和品种类型筛选品种的功能
- **搜索箱**: 该界面还应有个搜索箱，搜索箱的搜索范围为已筛选的品种，如不进行任何筛选则搜索箱的搜索范围为所有的品种
- **缓存机制**: 该缓存（仅指该缓存）无失效时间，下次调用api接口请求数据时自动覆盖

**主要依赖**:
- `infrastructure/data_module_vnpy/engine.py` - data_module_vnpy核心引擎，提供品种列表获取和管理功能
- `mootdx.quotes.Quotes.stock_all()` - 通达信股票品种信息获取API，返回全市场股票列表
- `infrastructure/data_module_vnpy/block_parser.py` - 专门解析特殊品种（北证A股、T+0基金、包含可转债）的模块
- `infrastructure/data_module_vnpy/storage.py` - 使用Parquet格式的品种列表缓存存储管理

**辅助依赖**:
- `vnpy_tushare.tushare_datafeed.TushareDatafeed.query_bar_history()` - Tushare品种信息查询接口
- `vnpy_rqdata.rqdata_datafeed.RqdataDatafeed.query_bar_history()` - RQData品种信息源
- `vnpy_ifind.ifind_datafeed.IfindDatafeed.query_history()` - iFind品种信息源
- `pandas.DataFrame.loc[]` - 品种数据筛选和过滤
- `pandas.DataFrame.sort_values()` - 品种数据排序

### 2.2 数据下载子界面

**功能描述**: 数据下载界面支持两种数据下载模式

#### 2.2.1 双模式数据下载链条

**功能说明**:

**主要依赖**:
- `infrastructure/data_module_vnpy/engine.py` - data_module_vnpy核心引擎，提供K线数据全量下载和增量下载方法
- `infrastructure/data_module_vnpy/stock_fetcher.py` - 股票数据获取器，支持全品类数据下载

### 2.4 数据源管理子界面

**功能描述**: 数据源管理是负责连接/断开实时数据源。预设数据源配置：data_engine（无需账号密码）、ifind（需要账号密码）、rqdata（需要账号密码）、tushare（需要账号密码）。数据源管理界面有连接按钮（多个数据源互斥，只能选一个），点击后与给定数据源建立初始连接。还有一个启动/停止按钮，点击后数据源开始推送数据/停止推送数据。数据源管理界面应有状态栏，无需用户请求自动刷新数据源状态：连接断开状态/连接，但未推送数据状态，数据推送状态。实时数据推送时应有实时数据的recording功能，该功能无需手动启动，数据源的数据推送启动时自动录制并保存到本地缓存，保存位置可配置更改，该缓存以日为单位存在，次日会自动删除。
