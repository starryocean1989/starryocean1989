# CPU 风扇转速控制策略说明

## 一、风扇控制机制概述

CPU 风扇转速由主板 BIOS/UEFI 固件根据 CPU 温度自动调节，采用 **PWM (Pulse Width Modulation)** 控制方式。当 CPU 温度升高时，风扇转速会自动增加以增强散热；温度降低时，转速下降以减少噪音和功耗。

## 二、典型的 CPU 风扇转速曲线

### 2.1 标准温度-转速对应关系

大多数主板采用**线性或曲线型**风扇控制策略，以下是典型的温度-转速对应关系：

| CPU 温度 | 风扇转速策略 | PWM 百分比 | 说明 |
|---------|------------|-----------|------|
| **< 30°C** | 最低转速（静音模式） | 20-30% | 保持最低转速，安静运行 |
| **30-40°C** | 低转速 | 30-40% | 轻度负载，温和散热 |
| **40-50°C** | 中低转速 | 40-50% | 开始增加转速 |
| **50-60°C** | 中等转速 | 50-60% | 中等负载，稳定散热 |
| **60-70°C** | 中高转速 | 60-75% | 高负载，加强散热 |
| **70-80°C** | 高转速 | 75-90% | 接近警告温度，全力散热 |
| **80-90°C** | 最高转速 | 90-100% | 严重温度，最大转速散热 |
| **> 90°C** | 最大转速（100%） | 100% | 紧急散热，防止过热 |

### 2.2 AMD Ryzen 7 7700 推荐风扇曲线

针对 AMD Ryzen 7 7700（TDP 65W），推荐的 BIOS 风扇曲线设置：

```
温度 (°C)    PWM (%)    转速 (RPM) 说明
────────────────────────────────────────────
< 40        20-30       800-1200    静音模式
40-50       30-45       1200-1800   轻度负载
50-60       45-60       1800-2400   正常负载
60-70       60-75       2400-3000   高负载
70-80       75-90       3000-3600   警告温度
80-90       90-100      3600-4000+  严重温度
> 90        100         最大转速    紧急散热
```

**注意**：实际转速取决于风扇型号、散热器类型和主板 PWM 控制精度。

## 三、风扇转速提升触发温度

### 3.1 关键温度阈值

根据典型的 BIOS 风扇控制策略：

- **40°C** - 风扇开始**明显提升转速**（从静音模式转为主动散热）
- **50°C** - 风扇转速**显著增加**（进入中等转速范围）
- **60°C** - 风扇转速**大幅提升**（进入高转速范围）
- **70°C** - 风扇转速**接近最大值**（警告温度）
- **80°C** - 风扇转速**达到或接近 100%**（严重温度）

### 3.2 转速变化特点

1. **滞后（Hysteresis）机制**：
   - 为避免风扇频繁启停，BIOS 通常设置 2-5°C 的滞后
   - 例如：温度从 50°C 升到 52°C 时转速提升，但需要降到 48°C 才降低转速

2. **平滑过渡**：
   - 现代 BIOS 通常采用平滑的转速曲线，避免突然的转速变化
   - 转速变化通常有 1-3 秒的过渡时间

3. **多风扇协同**：
   - 如果系统有多个 CPU 风扇，它们会协同工作
   - 可能采用主从架构或区域控制策略

## 四、BIOS/UEFI 风扇控制设置

### 4.1 常见 BIOS 设置选项

大多数主板 BIOS 提供以下风扇控制选项：

1. **风扇控制模式**：
   - **自动/智能**：根据温度自动调节（推荐）
   - **手动/PWM**：手动设置固定转速或曲线
   - **DC 模式**：电压控制模式（老式风扇）

2. **风扇曲线设置**：
   - **静音模式**：偏向低转速，噪音小
   - **标准模式**：平衡噪音和散热
   - **性能模式**：偏向高转速，散热优先
   - **自定义曲线**：用户自定义温度-转速对应关系

3. **温度阈值设置**：
   - 可以设置不同温度点的 PWM 百分比
   - 通常有 4-8 个温度控制点可调

### 4.2 推荐 BIOS 设置（AMD Ryzen 7 7700）

```
风扇控制模式: 自动/智能
────────────────────────────────────
温度点 1: 30°C → 25% PWM
温度点 2: 40°C → 35% PWM
温度点 3: 50°C → 50% PWM
温度点 4: 60°C → 65% PWM
温度点 5: 70°C → 80% PWM
温度点 6: 80°C → 95% PWM
温度点 7: 90°C → 100% PWM
```

**告警条件**：
- CPU 温度 > 50°C
- 风扇转速 < 500 RPM
- 判定为风扇故障或停转

### 5.2 风扇转速监控指标

建议的监控阈值：

| 指标 | 正常范围 | 警告 | 严重 |
|-----|---------|------|------|
| **CPU 风扇转速** | 800-4000 RPM | < 500 RPM（温度>50°C） | < 200 RPM（温度>60°C） |
| **风扇转速/温度比** | 40-60 RPM/°C | < 30 RPM/°C | < 20 RPM/°C |

**说明**：
- 风扇转速本身没有固定"正常"值，取决于温度
- 关键指标是：**在给定温度下，风扇是否正常响应**
- 如果温度高但转速低，可能是风扇故障

### 5.3 风扇健康检查

```python
def check_fan_health(cpu_temp: float, fan_rpm: float) -> Dict[str, Any]:
    """检查风扇健康状态"""
    # 计算期望的最小转速
    expected_min_rpm = {
        30: 800,   # 30°C 时至少 800 RPM
        40: 1200,  # 40°C 时至少 1200 RPM
        50: 1800,  # 50°C 时至少 1800 RPM
        60: 2400,  # 60°C 时至少 2400 RPM
        70: 3000,  # 70°C 时至少 3000 RPM
        80: 3600,  # 80°C 时至少 3600 RPM
    }

    # 找到对应温度段的期望转速
    temp_key = min([k for k in expected_min_rpm.keys() if cpu_temp >= k], default=30)
    expected_rpm = expected_min_rpm[temp_key]

    health_status = "正常"
    if fan_rpm < expected_rpm * 0.7:  # 实际转速低于期望值的 70%
        health_status = "警告"
    if fan_rpm < expected_rpm * 0.5:  # 实际转速低于期望值的 50%
        health_status = "严重"

    return {
        "status": health_status,
        "current_rpm": fan_rpm,
        "expected_min_rpm": expected_rpm,
        "cpu_temp": cpu_temp,
        "rpm_ratio": fan_rpm / expected_rpm if expected_rpm > 0 else 0
    }
```

## 六、风扇转速优化建议

### 6.1 降低噪音

如果风扇噪音过大，可以：

1. **调整 BIOS 风扇曲线**：
   - 降低低温度段的 PWM 百分比
   - 增加温度滞后，减少频繁变速

2. **改善散热环境**：
   - 清理机箱灰尘
   - 改善机箱风道
   - 使用更好的 CPU 散热器

3. **使用静音风扇**：
   - 选择低噪音风扇（通常转速上限较低）
   - 使用水冷散热器（通常更安静）

### 6.2 提升散热性能

如果需要更好的散热（超频或高负载）：

1. **调整 BIOS 风扇曲线**：
   - 提高各温度段的 PWM 百分比
   - 降低温度滞后，更快响应

2. **增加风扇数量**：
   - 添加机箱风扇改善风道
   - 使用多风扇 CPU 散热器

3. **优化机箱布局**：
   - 确保进气和排气风扇平衡
   - 避免线缆阻挡风道

## 八、常见问题

### Q1: 风扇转速为什么一直在变化？

**A**: 这是正常的。风扇转速会根据 CPU 温度实时调整，温度波动会导致转速变化。如果变化过于频繁，可以：
- 增加 BIOS 中的温度滞后设置
- 检查 CPU 负载是否波动过大

### Q2: 风扇转速过低怎么办？

**A**: 检查以下几点：
1. BIOS 风扇控制模式是否正确设置
2. 风扇电源连接是否正常
3. 风扇是否被灰尘堵塞
4. 风扇是否老化（可能需要更换）

### Q3: 风扇转速过高（噪音大）怎么办？

**A**: 可以：
1. 在 BIOS 中调整风扇曲线，降低各温度段的 PWM 百分比
2. 检查 CPU 温度是否异常高（可能需要改善散热）
3. 更换静音风扇或水冷散热器

### Q4: 如何判断风扇是否正常工作？

**A**: 检查：
1. **温度响应**：CPU 温度升高时，风扇转速是否相应增加
2. **转速范围**：风扇转速是否在合理范围内（通常 800-4000 RPM）
3. **噪音**：风扇是否有异常噪音（可能表示轴承磨损）
4. **告警**：系统是否报告风扇故障告警

## 九、总结

### 关键温度阈值：

- **40°C** - 风扇开始**明显提升转速**
- **50°C** - 风扇转速**显著增加**
- **60°C** - 风扇转速**大幅提升**
- **70°C** - 风扇转速**接近最大值**
- **80°C** - 风扇转速**达到或接近 100%**

### 推荐设置：

- **BIOS 风扇控制**：自动/智能模式
- **风扇曲线**：平衡噪音和散热（标准模式）
- **监控告警**：CPU 温度 > 50°C 且风扇 < 500 RPM 时告警

### 最佳实践：

1. 保持 BIOS 风扇控制为自动模式（除非有特殊需求）
2. 定期清理风扇和散热器灰尘
3. 监控风扇转速和 CPU 温度的关联性
4. 如果风扇噪音过大或散热不足，考虑调整 BIOS 设置或更换硬件
