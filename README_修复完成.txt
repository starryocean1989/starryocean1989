📋 问题根因
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

通过仔细阅读《系统监控完整集成指南.md》，发现：

❌ 问题：
   SystemManagerService分发两个独立事件：
   - EVENT_SYSTEM_METRICS（只包含system数据）
   - EVENT_HARDWARE_SENSORS（只包含hardware数据）

   但UI代码在处理system事件时，试图从中获取hardware数据！
   结果：CPU温度永远是0，网络速度也可能显示不正常。

✅ 解决：
   添加数据缓存机制：
   - 当hardware事件到达时，缓存数据
   - 当system事件到达时，使用缓存的hardware数据更新CPU温度

文件：ui/modules/system_manager_view.py

修改1：第1692行 - 初始化缓存
   + self._cached_hardware_data = {}

修改2：第2244行 - 缓存hardware数据
   + self._cached_hardware_data = hardware_data.copy()

修改3：第2398行 - 使用缓存数据
   - hardware_data = metrics.get("hardware", {})
   + hardware_data = getattr(self, "_cached_hardware_data", {})

   - 否则无法读取硬件传感器
