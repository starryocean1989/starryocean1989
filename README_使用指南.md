## 故障排除

### Q1: UI仍然崩溃？
**A**: 不应该了。如果仍崩溃，请提供错误日志。

### Q2: 进程被强制终止？
**A**: 不应该了。现在进程会优雅退出，日志应显示"收到停止信号"。

### Q3: Parquet文件损坏？
**A**: 不应该了。空DataFrame会被拦截，不会保存。

### Q4: 指数仍在列表中？
**A**: 删除`data/cache/stock_list_classified.json`，重新生成。

### Q5: 下载很慢？
**A**:
- 检查网络连接
- 查看终端输出，确认进程数
- 查看CPU使用率（应为70-90%）

## 技术细节

### 为什么北交所需要特殊处理？
mootdx.Quotes.bars()不支持market=2（北交所），必须使用底层TdxHq_API。

### 为什么进度显示分两层？
- 终端详细（每10个）：开发调试用
- UI简单（每100个）：避免崩溃
- 日志详细（每10个）：事后分析用

### 为什么要设置stop_event？
工作进程在while循环中等待任务，必须通过stop_event通知它们退出，否则只能强制terminate，导致Parquet文件损坏。
