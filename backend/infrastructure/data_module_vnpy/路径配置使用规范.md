# 路径配置使用规范

## 🔒 强制规则

### ❌ 禁止事项

**绝对禁止**以下任何形式的相对路径使用：

```python
# ❌ 错误：直接使用相对路径
cache_dir = Path("./data/cache")
data_dir = Path("data/kline")

# ❌ 错误：直接读取配置值
cache_dir = config_manager.get("chinastock.cache_dir")

# ❌ 错误：使用错误的配置键
kline_path = config_manager.get("kline_path", "data/kline")

# ❌ 错误：从 SETTINGS 直接读取
from vnpy.trader.setting import SETTINGS
cache_dir = SETTINGS.get("chinastock.cache_dir")
```

### ✅ 正确用法

**唯一正确**的路径获取方式：

```python
from backend.infrastructure.data_module_vnpy.config import config_manager

# ✅ 正确：使用专用方法获取绝对路径
cache_dir = config_manager.get_cache_dir()  # 返回 Path 对象，已转换为绝对路径
data_dir = config_manager.get_data_dir()    # 返回 Path 对象，已转换为绝对路径
```

## 🛡️ 防御机制

### 三层防护

1. **初始化时转换**（第一层）
   - `ConfigManager.__init__()` 自动调用 `_normalize_paths_on_init()`
   - 加载配置后立即检查并转换相对路径
   - 转换后立即持久化到 `vt_setting.json`

2. **访问时验证**（第二层）
   - `get_cache_dir()` 和 `get_data_dir()` 方法内置相对路径检测
   - 如果检测到相对路径（用户手动修改配置），自动转换并持久化
   - 发出 `logger.warning` 提示

3. **路径解析标准化**（第三层）
   - 使用 `get_project_root()` 动态检测项目根目录
   - 基于项目根目录解析相对路径
   - 确保跨环境一致性

## 📋 代码审查清单

在添加任何使用路径配置的新代码时，必须检查：

- [ ] 是否使用了 `config_manager.get_cache_dir()` 或 `get_data_dir()`？
- [ ] 是否避免了直接使用 `config_manager.get("chinastock.cache_dir")`？
- [ ] 是否避免了硬编码相对路径（如 `"./data/cache"`）？
- [ ] 是否在类的 `__init__` 方法中获取路径，而非模块级？

## 🔍 已修复的历史问题

### 问题案例1：`core.py` 第157行

**错误代码**：
```python
kline_path = config_manager.get("kline_path", "data/kline")
kline_dir = Path(kline_path)
```

**问题**：
1. 使用了错误的配置键 `"kline_path"`（应为 `"chinastock.data_dir"`）
2. 默认值是相对路径 `"data/kline"`
3. 没有使用标准方法

**修复后**：
```python
# 🔧 修复：使用标准方法获取数据目录，确保使用绝对路径
kline_dir = config_manager.get_data_dir()
```

## 🚨 常见错误与排查

### 错误1：数据保存到错误的目录

**症状**：数据保存到 `C:\Users\USER\data\kline` 而非项目目录

**原因**：使用了相对路径，工作目录不是项目根目录

**排查**：
```python
# 检查配置是否为绝对路径
print(config_manager.get("chinastock.data_dir"))  # 应该是绝对路径

# 正确获取
data_dir = config_manager.get_data_dir()
print(data_dir)  # 应该是 C:\Users\USER\Desktop\terminal_v0.50\data\kline
```

### 错误2：路径不存在

**症状**：`FileNotFoundError` 或 `目录不存在` 警告

**原因**：路径配置错误或未创建目录

**排查**：
```python
cache_dir = config_manager.get_cache_dir()  # 自动创建目录
data_dir = config_manager.get_data_dir()    # 自动创建目录
print(f"Cache dir exists: {cache_dir.exists()}")
print(f"Data dir exists: {data_dir.exists()}")
```

## 🔄 架构流程

```
系统启动
  ↓
backend/infrastructure/data_module_vnpy/config.py 加载
  ↓
config_manager = ConfigManager()  # 模块级实例化
  ↓
ConfigManager.__init__()
  ├─ _load_config()  # 从 vt_setting.json 加载配置
  └─ _normalize_paths_on_init()  # 🔧 转换相对路径为绝对路径
      ├─ 检查 chinastock.cache_dir
      ├─ 检查 chinastock.data_dir
      └─ _save_to_file()  # 持久化绝对路径
  ↓
其他模块导入 config_manager
  ↓
调用 config_manager.get_cache_dir() / get_data_dir()
  ├─ 双重保险：再次检查相对路径
  └─ 返回 Path 对象（绝对路径）
```

## ✅ 最佳实践

1. **始终使用专用方法**
   ```python
   from backend.infrastructure.data_module_vnpy.config import config_manager

   # 在类中
   class MyService:
       def __init__(self):
           self.cache_dir = config_manager.get_cache_dir()
           self.data_dir = config_manager.get_data_dir()
   ```

2. **路径拼接使用 Path 对象**
   ```python
   data_dir = config_manager.get_data_dir()
   symbol_dir = data_dir / symbol / interval
   file_path = symbol_dir / "data.parquet"
   ```

3. **日志输出使用绝对路径**
   ```python
   logger.info(f"保存数据到: {file_path.resolve()}")
   ```
