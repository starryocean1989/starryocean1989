### 2.4 数据传递路径验证

#### 步骤1: 验证监控进程数据

```python
import asyncio
import json
from backend.infrastructure.native.native_ipc import AsyncIPCPipe

async def verify_data():
    async with AsyncIPCPipe.client("monitor_query") as pipe:
        request = json.dumps({'action': 'get_data'}).encode()
        await pipe.write(request)
        response_data = await pipe.read()
        data = json.loads(response_data.decode())

        # 验证数据路径
        network_subsystem = data.get('system', {}).get('network_subsystem', {})
        socket_buffer = network_subsystem.get('socket_buffer_info', {})

        if socket_buffer:
            print("✅ Socket缓冲区数据存在")
            print(f"   TCP连接数: {socket_buffer.get('tcp_connections', 0)}")
        else:
            print("❌ Socket缓冲区数据不存在")

asyncio.run(verify_data())
```

## 三、问题排查

### 3.1 数据未显示

**症状**: 前端UI不显示Socket缓冲区信息

**排查步骤**：
1. 检查监控进程是否运行
   ```bash
   # 查看进程
   tasklist | findstr python
   ```

2. 检查日志文件中的错误
   ```bash
   Get-Content logs\application_startup_*.log | Select-String -Pattern "ERROR|异常|失败"
   ```

3. 验证后端数据采集
   ```python
   from backend.infrastructure.system_vnpy.monitor_system import SystemMonitor
   monitor = SystemMonitor()
   buffer_info = monitor.get_socket_buffer_info()
   print(buffer_info)  # 应该返回非空字典
   ```

### 3.2 数据异常

**症状**: 显示的数据明显不正确

**排查步骤**：
1. 对比系统工具统计
   ```bash
   # Windows
   netstat -an | findstr ESTABLISHED | find /c "TCP"
   ```

2. 检查日志中的调试信息
   ```bash
   Get-Content logs\application_startup_*.log | Select-String -Pattern "SOCKET-BUFFER.*统计完成"
   ```

3. 验证数据格式
   - 检查返回值是否为字典
   - 检查字段类型是否正确

### 3.3 UI显示异常

**症状**: UI显示错误或崩溃

**排查步骤**：
1. 检查浏览器控制台（F12）
   - 查看是否有JavaScript错误
   - 检查网络请求是否成功

2. 验证数据格式
   - 检查前端接收到的数据格式
   - 验证字段名是否匹配

3. 检查前端代码
   - 验证 `update_socket_buffer_info()` 方法是否存在
   - 检查数据更新逻辑
