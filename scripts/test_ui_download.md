## UI测试步骤

### 步骤1: 启动应用

```bash
cd C:\Users\USER\Desktop\terminal_v0.50
.\启动终端（增强版）.bat
```

或者使用Python直接启动：

```bash
cd C:\Users\USER\Desktop\terminal_v0.50
.\venv310\Scripts\python.exe ui\startup_coordinator.py
```

### 步骤2: 打开数据中心

1. 应用启动后，在主界面找到"数据中心"选项卡
2. 点击进入数据中心界面

### 步骤3: 加载品种列表（如果需要）

1. 在数据中心界面，找到"品种列表"选项卡
2. 点击"重新加载品种"按钮
3. 等待品种列表加载完成（应该显示约5000个品种）

### 步骤4: 配置服务器参数

1. 切换到"数据下载"选项卡
2. 点击"⚙ 服务器配置"按钮
3. 设置并行进程数（建议3-5个）
4. 点击确定保存

### 步骤5: 开始下载

1. 在"数据下载"选项卡
2. 选择开始日期（建议选择最近5-10天）
3. 点击"开始下载"按钮
4. 观察以下内容：
   - 进度条应该开始移动
   - 进度文本应该显示"正在下载..."
   - 详细进度表应该显示各个品种的下载状态
   - 日志应该显示worker进程启动信息

### 步骤6: 观察日志

在应用运行目录下，查看以下日志文件：

```
logs/terminal_v0.50.log
```

应该能看到类似以下的日志：

```
INFO - 开始多进程下载: X品种 × 3周期 = Y任务
INFO - 可用服务器数量: 38
INFO - 启动5个工作进程（进程池模式）
INFO - 开始监控进度，总任务数: Y
INFO - Worker 0 启动，PID: XXXXX
INFO - Worker 1 启动，PID: XXXXX
...
INFO - 收到进度: 000001 1d (1/Y)
...
INFO - 监控完成: 收到 X 个结果，完成 Y 个任务
INFO - 下载完成: X/Y 有效任务
```

## 预期结果

### ✅ 成功标志

1. **服务器验证**
   - 日志显示"服务器验证完成: 38/38 可用"或类似信息
   - 至少有20个以上可用服务器

2. **进程启动**
   - 日志显示"启动N个工作进程（进程池模式）"
   - 每个Worker显示"Worker X 启动，PID: XXXXX"
   - 进程数与配置的数量一致

3. **数据下载**
   - 进度条持续更新
   - 进度文本显示当前下载的品种
   - 最终显示"下载完成"消息
   - 成功率 > 80%

4. **数据存储**
   - 在`data/kline/`目录下能看到新的数据文件
   - 文件命名格式: `品种代码_周期.csv` (例如: `000001_1d.csv`)
   - 文件内容包含OHLCV数据

### ⚠️ 可能的问题

1. **服务器验证失败**
   - 原因: 网络问题或服务器不可达
   - 解决: 检查网络连接，等待片刻后重试

2. **进程启动失败**
   - 原因: 权限问题或资源不足
   - 解决: 以管理员身份运行，或减少进程数

3. **下载超时**
   - 原因: 网络慢或品种数量太多
   - 解决: 减少品种数量，或增加超时时间

4. **部分下载失败**
   - 原因: 个别服务器不稳定
   - 解决: 正常现象，重试失败的品种即可
